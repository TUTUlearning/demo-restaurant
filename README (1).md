# PANRUTI RESTAURANT — Website

A responsive multi-page restaurant website using HTML and CSS, with a small JavaScript interaction for WhatsApp enquiries.

## Pages

- `index.html` — Home
- `about.html` — About the restaurant
- `ambience.html` — Restaurant ambience
- `menu.html` — Menu
- `booking.html` — Table booking enquiry
- `services.html` — Services
- `media.html` — Photo gallery
- `contact.html` — Contact and enquiry form
- `style.css` — Shared styles

## Publish with GitHub Pages

1. Upload all website files to the **root** of your GitHub repository. Keep the filenames and capitalization unchanged.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/(root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The published address will appear in the Pages section.

The home page must be named `index.html` and must be in the repository root.

## Before publishing

Replace all sample information with verified restaurant details:

- Phone and WhatsApp numbers
- Exact address and Google Maps location
- Opening hours
- Menu items and prices
- Social media links
- Stock photos with the restaurant's own photos, if available

The booking and contact forms prepare a message in WhatsApp. They do **not** create a confirmed reservation or automatically send the message. Update the placeholder WhatsApp number in `booking.html` and `contact.html` to the restaurant's actual number, using digits only and including the country code (for India, `91`).

## Photos and external resources

The pages use illustrative photos hosted by Unsplash and Google Fonts for typography. An internet connection is required for those remote resources to load. Replace sample images with photos you have permission to use.
